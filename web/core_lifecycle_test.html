Core SQLite WASM Lifecycle Test

Phase 1 Validation: This test validates the fundamental SQLite database lifecycle operations through the WASM boundary. It establishes the foundation that all subsequent phases depend on.

🧪 What This Test Validates

  • WASM Module Initialization: SQLite 3.50.3 loads and initializes correctly
  • Database Lifecycle: Open :memory: database → use → close workflow
  • Statement Preparation: SQL compilation through sqlite3_prepare_v2()
  • Statement Execution: SQL execution through sqlite3_step()
  • Resource Management: Proper cleanup via sqlite3_finalize() and sqlite3_close()
  • Error Handling: Comprehensive error detection and propagation
  • Dart-JS-WASM Chain: Complete interop validation for core operations

📋 Test Sequence

  • Initialize SQLite WASM module with WASI stubs
  • Open in-memory database (:memory:)
  • Prepare and execute CREATE TABLE statement
  • Prepare and execute INSERT statement
  • Finalize all prepared statements
  • Close database connection
  • Verify all operations return correct SQLite result codes
